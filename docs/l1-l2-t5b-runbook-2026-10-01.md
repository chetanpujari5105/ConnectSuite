## 1 · What T5-B tests, and what it does not

- **The rule:** `docs/large-file-l1-l2-rules-2026-09-29.md` S4 and D1; `docs/protocol.md` → *Block-verified,
  resumable pulls* → `resume`. When the Mac asks to resume, the phone accepts only if the source's
  **current** size and last-modified equal the request's; otherwise it answers
  `{"accepted":false,"why":"source-changed"}`, and *"a refused resume is still a valid begin: the pull starts
  at 0 and the Mac deletes its partial and record first."*
- **So the expected outcome is a restart, not a failure.** The old partial (a prefix of the *old* bytes) is
  never spliced to new bytes; the whole *changed* file is fetched again from byte 0 and published. No
  `.failed` is expected. This is different from T5-A (S9: `SOURCE_CHANGED`, nothing published, `.failed`).
- **Not tested:** a change that keeps size **and** last-modified (the prefix re-hash, `prefix-mismatch`); a
  change during an active transfer (T5-A); anything on another root.

### Two facts from the code the run depends on

1. **The phone's size and last-modified come from MediaStore**, not the file:
   `DownloadsStore.entryAt` reads `MediaStore.Downloads.SIZE` and `DATE_MODIFIED` (**seconds**, ×1000). A
   change counts only if MediaProvider updates that row after the write. Unmeasured — so it is a gate (§6.3),
   observed through the product's own `fs.stat` and never faked.
2. **`downloads:connectsuite` lists only rows this app created** (the selection is `RELATIVE_PATH` under scoped
   storage), so the source must arrive through the product's push (`fs-send`), as T1's file did. A file put
   there by `adb push` would not appear in the pane.

### A gap to record, not a pass criterion

The rules doc §4 says the pane will show *"The file changed on the phone since it paused, so it started again
from the beginning."* **No shipping Mac source contains that sentence** (`grep` of `desktop/src`, tests
excluded). The pane will show the restart's ordinary success text. The run records the gap; it does not grade it.
